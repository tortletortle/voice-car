# 亚博 Voice-ASR-TTS 固件重烧备忘（无声时用）

仅在 **红灯已亮仍喇叭无声**，或怀疑固件被擦空 / 滑动开关长期停在烧录档时使用。

## 资料从哪下

- [亚博 Voice-ASR-TTS 教程](https://www.yahboom.com/study/Voice-ASR-TTS) → 下载区固件 / 协议表  
- [课程条目](https://www.yahboom.com/build?id=13114&cid=704)  
- 硬件说明：[博客园](https://www.cnblogs.com/FBsharl/p/18974491)（滑动开关、RST、Type-C）

本仓**不内嵌**厂商包。可临时放到工作区 `07_Temp/yahboom-voice-flash/`。

## 烧录要点（亚博板）

1. 模块 **Type-C** 接电脑。  
2. **滑动开关拨到烧录档**（串口切到 CI1302 / STC8 下载，以教程图为准）。  
3. 打开亚博/启英泰伦烧录工具，型号选 **CI1302**（协处理另跟教程选 STC8H）。  
4. 导入出厂 `.bin`，勾选对应 COM。  
5. 按模块 **RST**，开始下载。  
6. 成功后：**滑动开关拨回运行档**，取消工具端口勾选，重新上电。  
7. 验收：说 **`Hi, Yahboom`** 或 **`小亚小亚`**，听喇叭应答。

## 禁止

- 烧完仍停在烧录档就测唤醒  
- 超 5V 供电  
- 用错芯片型号  
- 继续用 M5「Debug Rst + Hi M Five」当本板默认流程  

## 与发声验收的关系

见 `发声验收.md`：红灯 → 开关档位 → 正确唤醒词 → **本页重烧**。
