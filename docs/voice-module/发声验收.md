# 发声验收（喇叭出声）— 亚博 Voice-ASR-TTS

**硬卡点**：模块喇叭无声。  
**已纠正**：本车模块按用户链接为 **亚博 Voice-ASR-TTS**（[教程](https://www.yahboom.com/study/Voice-ASR-TTS)、[课程](https://www.yahboom.com/build?id=13114&cid=704)），**不是** M5 Module ASR。

芯片仍是 CI1302，但出厂唤醒词 / 播报 / 串口帧按**亚博固件**。详见 [`亚博Voice-ASR-TTS.md`](亚博Voice-ASR-TTS.md)。

---

## 1. 验收口令（先听喇叭）

| 步骤 | 动作 | 期望 |
|---|---|---|
| 供电 | Type-C 或 H1 **5V** | **红灯常亮** |
| 开关 | 滑动开关在**运行档**（非烧录） | 可识别 |
| 唤醒 | **`Hi, Yahboom`**（慢说）或 **`小亚小亚`** | 喇叭 **`I am here` / 我在`** |
| 休眠 | ~20s 无命令 | 可能播休息语，需再唤醒 |

参考：[Get started quickly](https://www.yahboom.net/public/upload/upload-html/1742021302/0.%20Get%20started%20quickly.html)。

**已废弃**：`Hi, M Five` / `I'm here`（那是 M5 口径）。

---

## 2. 供电与指示灯

| 现象 | 含义 |
|---|---|
| 红灯亮 | 5V 基本正常 |
| 红灯不亮 | 先查供电，勿查协议 |
| Type-C | 可供电+烧录 |
| 仅 TX/RX 无 5V | 不会正常发声 |

---

## 3. 失败树

```text
喇叭无声
 ├─ 红灯？否 → 接 5V
 ├─ 滑动开关在烧录档？ → 拨运行 + RST
 ├─ 唤醒词用了 Hi M Five？ → 改 Hi Yahboom / 小亚小亚
 └─ 仍无声 → 按亚博教程重烧出厂固件（拨码+RST）
```

---

## 4. 发声通过后再抓串口

亚博帧多为：`AA 55 00 XX FB`（识别上报），**不是** `AA 55 ID 55 AA`。  
本仓 ESP 解析器仍是 M5 格式 → **发声通过后再改代码**。

脚本：`python tools/voice_sound_check.py --port COMx`（仅辅助抓字节；以人耳为准）。
