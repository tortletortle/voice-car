# 接线与探测

**优先**：喇叭是否出声 → 先做 [`发声验收.md`](发声验收.md)。本页是发声通过后的 UART/ESP 探测。

## 1. 接线（本仓口径）

```text
CI1302 模块                ESP32-S3 DevKit (U2)
─────────────────          ────────────────────
TX1 / UART_TX  ──────────► GPIO17  (VOICE_RX, ESP RX)
RX1 / UART_RX  ◄────────── GPIO18  (VOICE_TX, ESP TX)
GND            ─────────── GND
VCC            ─────────── H1=+5V（以原理图为准）
```

- **必须交叉**：模块 TX → ESP RX（`VOICE_RX`），模块 RX ← ESP TX（`VOICE_TX`）  
- 电源共地；勿把模块 TX 接到 ESP TX  
- 底板 H1：1=+5V，2=GND，3=`VOICE_RX`，4=`VOICE_TX`  
- 原理图 U2：`VOICE_RX`=GPIO17，`VOICE_TX`=GPIO18（**不是** GPIO10/11）

源码宏（`voice_uart.c`）：

| 宏 | 值 |
|---|---|
| `VOICE_UART_NUM` | `UART_NUM_1` |
| `VOICE_TXD_GPIO` | 18 |
| `VOICE_RXD_GPIO` | 17 |
| `VOICE_BAUD` | 115200 |

## 2. 上电探测逻辑（已实现）

1. 装 UART，115200  
2. 听 3 s：有字节 → 打 `voice 115200 bytes=N` + HEX  
3. 无字节 → 改 9600 再听 3 s  
4. 仍无 → 打 `NO BYTES on GPIO17`，波特率改回 115200  
5. 之后每 2 s 继续听并打 HEX（仍不映射命令）

## 3. 验收

1. 先接好共地与交叉 UART，再上电 ESP  
2. `idf.py -p COMx monitor` 看 `voice_uart` 标签  
3. 对麦克风说唤醒词/命令，应出现 `voice rx …` 与 HEX  
4. 禁止在无字节时改词表映射代码（先查线、电平、波特率、模块是否已唤醒）

## 4. 常见坑

| 现象 | 先查 |
|---|---|
| 全程 0 字节 | 交叉反了、模块未供电、GPIO 错、拨码未选到该 UART |
| 乱码 | 波特率不对；本仓已自动试 9600 |
| 有字节但不像帧 | 固件协议不同（见 `协议参考.md`） |
| 只听到噪声字节 | 共地差 / 线太长 / 电平不匹配 |
