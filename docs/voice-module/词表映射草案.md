# 词表 → 车控映射草案

目标：模块识别结果 → `vc_cmd_t` → `cmd_router_submit` → STM32。

`ID` 列留空或标「待填」：必须用**本板固件**实际发出的 ID；下表中文词是产品建议，不是出厂默认英文词。

## 1. 映射表（草案）

| 建议说法（中文） | 建议说法（英文备选） | 模块 ID（待填） | `vc_cmd_t` | 值 |
|---|---|---|---|---|
| （唤醒，不驱动车） | Hi / 小车小车 | | — | 仅点亮/忽略 |
| 停止 / 停车 | stop | | `CMD_STOP` | `0x01` |
| 前进 | forward / go | | `CMD_FWD` | `0x02` |
| 后退 | back / backward | | `CMD_BACK` | `0x03` |
| 左转 | turn left | | `CMD_LEFT` | `0x04` |
| 右转 | turn right | | `CMD_RIGHT` | `0x05` |
| 抬头 / 云台向上 | gimbal up | | `CMD_GIMBAL_UP` | `0x10` | 一次到 -45° |
| 低头 / 云台向下 | gimbal down | | `CMD_GIMBAL_DOWN` | `0x11` | 一次到 0° |
| 云台向左 | gimbal left | | `CMD_GIMBAL_LEFT` | `0x12` | SERVO2 定住 1000µs |
| 云台向右 | gimbal right | | `CMD_GIMBAL_RIGHT` | `0x13` | SERVO2 定住 2000µs |
| 云台回中 | gimbal center | | `CMD_GIMBAL_CENTER` | `0x14` | 仅俯仰中点 |
| 偏航回中 | gimbal yaw stop / center yaw | | `CMD_GIMBAL_YAW_STOP` | `0x15` | SERVO2 → 1500µs |
| 摇头 | shake head / gimbal shake | | `CMD_GIMBAL_YAW_SHAKE` | `0x16` | 左→右→左→回中 |
| 点头 | nod / gimbal nod | | `CMD_GIMBAL_PITCH_NOD` | `0x17` | 低头→抬头→回中 |

无 ASR 时可用 PC 注入（ESP 已接）：`VC UP` / `VC DOWN` / `VC NOD` / `VC SHAKE`，见 `tools/gimbal_vc_test.py`。

## 2. 实现约定（落地时）

1. 在 `voice_uart` 解出模块 ID 后查表；命中则 `cmd_router_submit(cmd)`  
2. 唤醒 ID **不要**映射成运动命令  
3. 未知 ID：打日志，不提交  
4. 队列已是「最新覆盖」：连说多句时后一句生效  
5. 中文词表通常需**重新生成模块固件**（见 `资料链接.md`）；仅改 ESP 映射改不了麦克风听什么  

## 3. 填表方法

1. `monitor` 抓到完整一帧，记下 ID 字节  
2. 口头确认对应说法，写入上表「模块 ID」  
3. 同一说法重复 3 次 ID 应一致，再写进代码常量数组  

## 4. 与 OLED 标签对齐

OLED L1 命令标签见仓库 `docs/oled-content.md`（`FWD`/`RGHT`/`G-UP` 等）。映射稳定后再接显示刷新。
