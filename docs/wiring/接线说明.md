# Voice Car — 接线图与板级约定

来源：仓库冻结口径（2026-11-15 用户确认 + bringup 实测）。  
电机到 MCU 的具体 GPIO 以底板 PCB（`01_Projects/PCB`）丝印/网表为准，本仓未写死。

## 1. 总览

```text
CI1302                ESP32-S3 DevKit (U2)              STM32F103 (U1)
───────               ───────────────────              ───────────────
TX1 ──► GPIO17 RX（VOICE_RX）
RX1 ◄── GPIO18 TX（VOICE_TX）
                      GPIO5 TX ──交叉──► PB11 RX (U1.36)
                      GPIO4 RX ◄─交叉── PB10 TX (U1.35)
                                                         PB6 SCL ──► OLED
                                                         PB7 SDA ──► OLED
                                                         MotA/MotB ──► TB6612 J4A/J4B
                                                         SERVO1/2（bringup 暂停）
```

数据流：语音或遥控 → ESP32 归一 `vc_cmd_t` → 6 字节帧 → STM32 → 差速限时停 / 云台限幅。

## 2. 板间 UART（已实测）

| 网名 | 方向 | ESP32-S3 | STM32 | 连接器脚 |
|---|---|---|---|---|
| `ESP32_TX` | ESP → STM | GPIO5 TX | PB11 RX | U1.36 |
| `ESP32_RX` | STM → ESP | GPIO4 RX | PB10 TX | U1.35 |

- 波特率：115200 8N1
- **必须交叉**（TX↔RX）
- bringup：HSI 8 MHz，`BRR=0x45`（约 115942，误差 ~0.6%）
- 预期：STM32 周期打印 `LINK`；ESP 侧可见 `stm32: LINK` 一类日志

## 3. 语音 UART（CI1302 ↔ ESP）

| 信号 | ESP GPIO | 含义 |
|---|---|---|
| `VOICE_RX` | GPIO17 | 模块 TX1 → ESP RX |
| `VOICE_TX` | GPIO18 | ESP TX → 模块 RX1 |

上电先听 115200，无字节再试 9600。词表→命令映射仍待补。

## 4. OLED（STM32）

| 项 | 值 |
|---|---|
| 接口 | I2C |
| SCL | PB6（U1.14） |
| SDA | PB7（U1.15） |
| 地址 | 先 0x3C，失败再 0x3D |
| bringup | 成功显示「OK」，串口 `OLED OK` |
| 正式固件 | `OLED_ENABLED=0`（Phase 2） |

文案规范见同包 `oled-content.md`。

## 5. 电机 / 云台 / 电源

### 电机（TB6612 风格，J4A/J4B）

| 通道 | 用途 | 信号 |
|---|---|---|
| MotA | 左轮 | AIN1, AIN2, PWA |
| MotB | 右轮 | BIN1, BIN2, PWB |
| 共用 | 使能 | STBY（有运动才拉高，停拉低） |
| C/D | 本版不用 | 软件不驱动 |

- 前进/后退默认 1500 ms 自停；转向 800 ms
- PWM ≤30%（电机+舵机共 5V，联调硬帽）
- 左右反了改 `MOTOR_SWAP_LR`；单轮反了改 `MOTOR_INVERT_L/R`
- **MCU↔驱动桥具体脚位：固件 TODO，对 PCB**

### 云台

| 项 | 值 |
|---|---|
| SERVO1 | 俯仰定位：`0°=低头`，`-45°=抬头`，行程 [-45,0] |
| SERVO2 | 偏航定位：左1000 / 中1500 / 右2000µs；摇头 `0x16` |
| SERVO1 中心 / 步进 | `-22°`（中点） / `5°` |

### 电源

- 共 5V 联调勿盲目拉高 PWM
- 逻辑地与电机地共地；大电流回路尽量短
- STBY 上电宜默认低（核对板上拉/下拉）

## 6. 命令帧（v0）

```text
AA 55  CMD  LEN  SEQ  CHK
                 └─ LEN=1；CHK = CMD ^ LEN ^ SEQ
```

| 符号 | 值 |
|---|---|
| CMD_STOP | 0x01 |
| CMD_FWD | 0x02 |
| CMD_BACK | 0x03 |
| CMD_LEFT | 0x04 |
| CMD_RIGHT | 0x05 |
| CMD_GIMBAL_UP | 0x10 |
| CMD_GIMBAL_DOWN | 0x11 |
| CMD_GIMBAL_LEFT | 0x12 |
| CMD_GIMBAL_RIGHT | 0x13 |
| CMD_GIMBAL_PITCH_CENTER（旧 CENTER） | 0x14 |
| CMD_GIMBAL_YAW_STOP | 0x15 |
| CMD_GIMBAL_YAW_SHAKE | 0x16 |

俯仰在 **SERVO1**：UP=抬头（→-45），DOWN=低头（→0），CENTER→-22。  
偏航在 **SERVO2**：LEFT/RIGHT 定住 + YAW_STOP 回中 + YAW_SHAKE 摇头；屏显 `CTR/LEFT/RGHT/SHAK`。  
定义见仓库 `firmware/common/cmd_protocol.h`（云端 V0.3 设计）。

## 7. 接线核对

1. 先共地
2. ESP GPIO5 → STM PB11；ESP GPIO4 ← STM PB10（交叉）
3. 语音：模块 TX→GPIO17（VOICE_RX），模块 RX←GPIO18（VOICE_TX）
4. OLED：SCL→PB6，SDA→PB7
5. 烧 `bringup.hex`：看 `LINK` / `OLED OK` / `SERVO OFF`
6. **禁止**：把旧 `voice-car-pcb` 概念稿当现行基线；未确认舵机方案勿开 TIM2；引脚勿散落硬编码进业务 `.c`
