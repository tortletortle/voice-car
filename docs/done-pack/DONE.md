## 1. 电机 / 云台 — 做好了什么、缺什么

**已有（逻辑层，完整）：**

- `motion.c`：FWD/BACK/LEFT/RIGHT/STOP、限时自停、默认 PWM 帽  
- `gimbal.c`：上下左右步进、回中、45～135 限幅  
- `board.h`：时间/PWM/云台参数策略已冻结  

**没有（硬件驱动层，仍是 TODO 桩）：**

- `Bsp/motor.c`：不写 TIM/GPIO，只做左右交换与 STBY 状态变量  
- `Bsp/servo.c`：空实现  

所以：**不能叫「完整电机和云台驱动」**；叫「完整运动/云台状态机」才准确。本包只收逻辑层 + 头文件，不把空 BSP 冒充完整驱动。

## 2. OLED 实际绘图 — 做好了什么

- SSD1306/SH1106 兼容刷页

**没有：** 按 `oled-content.md` 四行状态屏的正式 UI（规范在包内 `oled-content-spec.md`，代码未合入 App）。

## 3. ESP32 `cmd_router` + `app_main` — 完整且可用

- `cmd_router.c`：长度 1 队列、`Overwrite`=最新优先、`poll`→`link_stm32_send`  
- `app_main.c`：初始化链路/路由/语音/遥控占位，10 ms 轮询  

这是当前架构下的**完整实现**（语音映射、联网仍在别的组件里未完成，不在这两个文件职责内）。
